### 🛡️ Lightweight Intrusion Detection System for IoT — Degree Project

**Status:** Research and documentation phase

My degree project focuses on the design of a lightweight Intrusion Detection System (IDS) for IoT environments using Raspberry Pi.

The research aims to explore network traffic analysis techniques for identifying port scanning, Denial-of-Service (DoS), and brute-force attacks while considering the computational limitations of resource-constrained devices.

**Current activities:**
- Reviewing scientific literature and technical documentation.
- Studying IoT security threats and relevant traffic patterns.
- Defining the system architecture and detection approach.
- Planning tests for detection capability and resource consumption.

**Research areas:** `Cybersecurity` `IoT Security` `Network Traffic Analysis` `IDS`

*Implementation and experimental evaluation have not started yet.*
